# Supplementary material

This directory carries the supplementary material for the MedTrajectory manuscript.

## `v14_submission/` — material for the submitted version

| File | Contents |
|---|---|
| `Manuscript_v14_Short_Rebalanced_REVISED.docx` | Manuscript as submitted (Tables I–IV, Figures 1–5) |
| `Supplementary_v14_Short_Rebalanced_REVISED.docx` | Supplementary material as submitted: sections S1–S7 and S13, Tables S1–S12 and S13a–S13f |

The supplementary document uses the short-paper numbering. Its numerical tables are derived
from the aggregate summaries in [`../results/aggregate/`](../results/aggregate/); no
patient-level records are distributed.

## `Supplementary_Material_v13_longform.docx` / `Supplementary_Tables_v13_longform.xlsx`

The earlier, longer-form supplementary material (dated 2026-10-08), retained for reference
because it documents the protocol in more depth than the submitted short version:

- `Supplementary_Material_v13_longform.docx` — supplementary methods S1–S12, figure
  captions, and prose accompanying Tables S1–S33;
- `Supplementary_Tables_v13_longform.xlsx` — workbook with an index plus worksheets
  S1–S33 (34 sheets).

Note that the long-form document uses a **different section and table numbering** from
`v14_submission/`, and some of its values refer to superseded experiment versions. Where the
two disagree, `v14_submission/` is authoritative for the manuscript; the long-form document
is kept for protocol detail, not as a source of reported values.

Access-controlled UK Biobank and MIMIC-IV records are not redistributed in either version.
