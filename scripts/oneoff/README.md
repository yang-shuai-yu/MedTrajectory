# One-off and development-only scripts

These scripts are kept for provenance. They are **not** part of the
reproduction path for the reported results and may depend on artefacts or
queue managers that no longer exist.

Typical contents: manuscript text editing, internal packaging, environment
setup, result-registry bookkeeping, superseded ablation queues, and
one-off diagnostics from the development process.

A `59`-file listing is in the upload manifest (UPLOAD_MANIFEST.md).
